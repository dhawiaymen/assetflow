# Security policy

0.1.x is the currently maintained development series. Dependencies and browser
engines should be kept up to date. Run only games and assets you are authorized
to process; browser isolation is not a guarantee against malicious content.

Do not put credentials or personal data in bug reports. Use GitHub's private
vulnerability reporting if enabled on this repository. If it is unavailable,
open an issue asking for a private reporting channel without exploit details.
No response-time commitment is advertised.
