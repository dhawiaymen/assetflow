# Third-party dependencies

The project's original code is MIT licensed. Dependencies retain their own
licenses; the project license does not relicense them.

- Python and Tkinter: Python Software Foundation License; Tcl/Tk has its own license.
- Pillow (AssetFlow): HPND-style Pillow license and bundled codec notices.
- Playwright (GameTest AI): Apache-2.0; Chromium and browser components have
  separate third-party licenses.
- PyInstaller (build only): GPL with a distribution exception; consult its
  license and bundled notices for a binary distribution.
- Ollama and any downloaded language model are optional external software;
  check each chosen model's license separately. No model is redistributed here.

Before a binary release, retain the licenses/metadata that PyInstaller collects
and review the resulting dependency list. Source distributions include the MIT
license for original code and runtime templates.
