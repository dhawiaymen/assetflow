# Community Code of Conduct

We want AssetFlow to be useful and welcoming to contributors of all experience
levels. Be respectful, explain technical concerns clearly, and help others reproduce
problems. Credit other people's work and respect licenses.

Harassment, personal attacks, discriminatory language, threats, doxxing, spam,
and fabricated evidence are not acceptable. Disagreement about code is welcome;
attacks on people are not. Do not publish private information in issues or reviews.

Maintainer: [dhawiaymen](https://github.com/dhawiaymen). For an ordinary moderation
concern, open an issue asking the maintainer to contact you privately; do not include
sensitive details. A dedicated confidential contact is not yet available. For urgent
platform abuse, use GitHub's reporting tools. Security issues follow SECURITY.md.

The maintainer may edit or remove content, warn participants, or restrict participation
according to the severity and repetition of behavior. Decisions should explain the
specific behavior and avoid retaliation. This policy applies to project-controlled
issues, pull requests, discussions, and other official project spaces.
